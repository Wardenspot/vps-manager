# NordCam — своё приложение для видеонаблюдения (Android)

Замена Hik-Connect, которая работает с **любыми** камерами и регистраторами: Hikvision, HiWatch, EZVIZ,
Dahua, Imou, RVi, Uniview, XMEye/iCSee, Reolink, TP-Link Tapo/VIGI и всё, что умеет RTSP или ONVIF.
Видео идёт напрямую с камер на телефон — без чужих облаков и аккаунтов.

## Что умеет

**Просмотр**
- Сетка 1 / 4 / 9 / 16 камер, листание страниц, группировка по объектам (дом, офис, склад).
- В сетке — лёгкий поток (SD), на весь экран — основной (HD), переключение одной кнопкой.
- Полный экран с поворотом в альбомный режим, цифровой зум щипком, двойное касание — приблизить.
- Звук, снимок в галерею, запись вручную на телефон.
- PTZ: поворот и зум кнопками (держать — едет, отпустить — стоп), скорость, пресеты, «запомнить точку».
- Автопереподключение при обрыве, пауза при сворачивании (не тратит трафик).

**Добавление камер**
- Поиск в Wi-Fi сети по ONVIF: находит камеры и регистраторы, сам получает адреса потоков, все каналы NVR.
- По адресу: выбрать производителя, ввести IP/домен, логин и пароль; кнопка «Получить по ONVIF».
- Регистратор: все каналы разом.
- Свой RTSP-адрес для любой нестандартной камеры, кнопка «Проверить» показывает видео прямо в форме.

**Архив**
- С карты памяти камеры или диска регистратора (Hikvision, Dahua — сразу; для других — свой шаблон адреса):
  выбор дня в календаре, ползунок по времени суток, перемотка ±10 с / ±1 мин.
- Записи на телефоне: по движению, постоянная (отрезками) и вручную. Плеер с перемоткой и скоростью до 8×,
  отправка файла, сохранение в галерею. Лимит места — старые записи удаляются сами.

**Архив с серверов записи**
- Synology Surveillance Station (DSM 6/7) и Frigate NVR: «Ещё» → «Серверы записи».
- Шкала времени как в Hik-Connect: цветные полосы записей, засечки событий, масштаб 24 ч / 6 ч / 1 ч / 10 мин,
  выбор дня в календаре, автопереход к следующему отрезку.
- Frigate: список событий со снимками (человек, машина, животные, номера, лица).
- Камеры с сервера добавляются в NordCam одной кнопкой (живое видео через сервер) или связываются с уже добавленными
  — автоматически по IP и названию.
- Самоподписанный сертификат NAS поддерживается (видео идёт через встроенный прокси).
- Новая система подключается реализацией интерфейса `Nvr` (`net/Nvr.kt`).

**Детекция движения и тревоги**
- События самой камеры по ONVIF: движение, пересечение линии, вторжение в зону, человек, машина, закрытие объектива.
- Для камер без ONVIF-событий — сравнение снимков на телефоне с настройкой чувствительности.
- Пуш-уведомление со снимком, журнал событий со снимками, переход к записи или архиву с момента тревоги.
- Необязательно: дублирование тревог в Telegram своим ботом и на почту (Яндекс, Mail.ru, Gmail или свой SMTP-сервер).
- Работает в фоне, переживает перезагрузку телефона.

**Доступ для других**
- Выбираете камеры, права (онлайн / архив / поворот / запись) и срок (день, неделя, месяц, бессрочно).
- Приложение делает QR-код и ссылку, зашифрованные паролем (AES-256-GCM). Получатель сканирует QR в NordCam.
- Совет: для чужих людей заведите на камере отдельного пользователя «только просмотр» и делитесь им.

**Защита**
- PIN-код и вход по отпечатку, автоблокировка после сворачивания.
- Пароли камер хранятся в зашифрованном хранилище Android.

## Сборка

GitHub Actions (`.github/workflows/cctv.yml`) собирает APK при каждом изменении в ветке `cctv-app`.
Файл лежит в разделе **Actions → последняя сборка → Artifacts → NordCam-N**. Если в репозитории заданы секреты
`NK_KEYSTORE_B64` и `NK_KEYSTORE_PASSWORD` (те же, что у NordKey), APK подписывается и публикуется отдельным
предрелизом `nordcam-v1.0.N` — релиз NordKey при этом не меняется.

Код: Kotlin + Jetpack Compose, видео — libVLC (H.264/H.265, RTSP по TCP/UDP, MJPEG), ONVIF — свой лёгкий клиент.

## Если камера через интернет

Нужен доступ к камере снаружи: проброс портов RTSP (обычно 554) и HTTP/ONVIF (обычно 80) на роутере
либо VPN (WireGuard/AmneziaWG) до сети с камерами. Тогда в адресе указывается внешний IP или DDNS-домен.

## Ограничения первой версии

- Нет облачного P2P (как серийный номер в Hik-Connect) — нужен проброс портов или VPN.
- Нет двусторонней связи (разговор через камеру).
- Время архива Hikvision передаётся по местному времени телефона; если на регистраторе другой часовой пояс —
  поправьте шаблон архива в настройках камеры.
