# NordKey для Windows

Одно приложение `NordKey.exe` для клиентов и сотрудников: VPN на компьютере с маршрутизацией «как на роутере»,
а также те же экраны, что в приложении для Android (роутеры, подписка, поддержка; у сотрудников — клиенты, автопилот, ИИ).

## Как работает

- **VPN** — AmneziaWG (тот же сервер и те же параметры, что у роутеров). Компьютер — отдельное устройство клиента
  по его подписке: свой адрес 10.66.66.X и ключ (на сервере `configs.protocol = 'pc'`, модуль `nkpc.py`).
- **Маршрутизация как на роутере.** Через VPN идёт только нужное: списки сторожа сайтов, справочник приложений, то, чему
  научился ИИ, сети из списков бота и сайты, которые для клиента настроила поддержка. Всё остальное, включая игры, банки
  и российские сайты, идёт напрямую. Режимы «всё, кроме российского» и «всё через VPN» доступны только сотрудникам.
- **Как это устроено:** Windows спрашивает адреса сайтов у NordKey (правило NRPT). NordKey отвечает и перед ответом
  добавляет маршрут /32 через туннель для сайтов из списка VPN.
- **Сайты клиента** клиент добавляет через ИИ-поддержку («не работает игра на компьютере»): инструменты ИИ `pc_site`
  и `pc_info`. Сайт, который пустили на роутере клиента, автоматически включается и на его компьютере.
  Компьютер подхватывает изменения за пару минут.
- **Служба Windows «NordKey VPN»** работает от имени системы и держит VPN, в том числе после перезагрузки.
  Окно приложения — HTML в Edge (режим приложения) — обращается только к службе на `127.0.0.1:47811`, у окна свой ключ.
  Токен входа и ключи VPN окну не передаются. Состояние хранится в `C:\ProgramData\NordKey`: файл зашифрован DPAPI,
  доступ к папке — только у системы и администраторов.

## Установка (у клиента)

Скачать `NordKey.exe` и запустить. Windows один раз спросит разрешение — так ставится служба и драйвер wintun.
Появятся ярлыки на рабочем столе и в «Пуске». Удаление — через «Параметры → Приложения» («NordKey VPN»).

Файл пока без цифровой подписи, поэтому SmartScreen покажет «Windows защитила ваш компьютер».
Нужно нажать «Подробнее», затем «Выполнить в любом случае».

## Сборка

GitHub Actions (`.github/workflows/windows.yml`) запускается при изменениях в `windows/`. Шаги:

- тесты на Linux;
- сборка на Windows;
- скачивание `wintun.dll` с проверкой подписи WireGuard LLC.

Готовый файл — в выпуске `windows-latest`:
https://github.com/Wardenspot/vps-manager/releases/download/windows-latest/NordKey.exe

Проверка без Windows: `go test ./internal/...`. Ещё можно запустить `go run ./cmd/nordkey -api http://127.0.0.1:8765`
на Linux — тогда ядро VPN работает в режиме имитации, а окно открывается в браузере по ссылке из вывода.

## Устройство кода

| Папка | Что внутри |
|---|---|
| `internal/rules` | решение «VPN или напрямую» по домену (самый длинный суффикс, свои сайты главнее) |
| `internal/dnsproxy` | локальный DNS: выбор сервера, маршрут до ответа, без IPv6 для сайтов через VPN |
| `internal/engine` | туннель AmneziaWG + wintun, маршруты Windows, NRPT, смена сети (`engine_windows.go`) |
| `internal/app` | служба: вход через Telegram, подключение, локальный API окна, прокси к серверу |
| `internal/store` | сохранённое состояние (DPAPI) |
| `ui/` | окно приложения |
| `cmd/nordkey` | запуск: служба, установка, удаление, открытие окна |
