# NordDesk — свой удалённый доступ

Своё приложение удалённого доступа к ПК в стиле AnyDesk/RuDesktop: **один
`NordDesk.exe` для всех**. Скачал на два компьютера — продиктовал ID и код —
подключился. Соединение идёт через **твой** релей на VPS, а трафик зашифрован
сквозным ключом, которого у релея нет.

Чистый Go **без внешних зависимостей** (стандартная библиотека + прямые вызовы
WinAPI). Собирается в GitHub Actions.

## Как пользоваться

1. Скачать `NordDesk.exe` на оба компьютера:
   https://github.com/Wardenspot/vps-manager/releases/tag/norddesk-latest
2. Запустить. Слева — **«Это рабочее место»**: постоянный ID компьютера и
   одноразовый код. Справа — **«Подключиться к другому»**.
3. Подключение:
   - **ID + код** — подключение сразу, без вопросов на той стороне;
   - **только ID** — на той стороне всплывёт «Разрешить?» с проверочным номером,
     который виден и у подключающегося (сверить, что никто не вклинился).

В сеансе:

- **все сочетания клавиш уходят туда**: Win, Alt+Tab, Ctrl+W, Alt+F4 и т.д.
  (переключатель «Системные клавиши»; Ctrl+Alt+Del и Win+L Windows не отдаёт);
- **файлы**: перетащить файл или папку в окно — появятся на рабочем столе той
  стороны; или **Ctrl+C у себя → Ctrl+V там** — вставятся в открытую папку;
  или кнопка «Файлы…»;
- **буфер обмена** с текстом синхронизируется в обе стороны сам;
- **Инструменты**: cmd и PowerShell от администратора, диспетчер задач,
  «Выполнить», службы, диспетчер устройств, события, сеть, программы, панель
  управления, параметры, сведения о системе;
- **«Права администратора для NordDesk»** — перезапуск NordDesk на той стороне
  с правами администратора (там нужно один раз нажать «Да» в UAC), сеанс
  переподключается сам. Без этого Windows не даёт управлять окнами,
  запущенными от администратора (UIPI), — например, печатать в админском cmd;
- сеанс не рвётся, когда на той стороне открыт запрос UAC или экран
  блокировки — показывается уведомление.

Файл пока без цифровой подписи — SmartScreen покажет «Windows защитила ваш
компьютер»: «Подробнее» → «Выполнить в любом случае».

## Из чего состоит

| Компонент | Где | Что делает |
|-----------|-----|------------|
| `cmd/norddesk` → `NordDesk.exe` | Windows | Единое приложение: окно (HTML в Edge, режим приложения) + входящая и исходящая части. |
| `cmd/relay` → `norddesk-relay` | VPS (Linux) | Сводит компьютеры по ID и переливает байты. Содержимого не видит. |
| `cmd/host` | Windows | Входящая часть без окна — для серверов и своих машин (`-pw` — постоянный пароль). |

Пакеты: `internal/hostagent` (входящая часть: ID, код, согласие, сеанс),
`internal/secure` (сквозное шифрование), `internal/relaysrv` + `internal/relaylink`
(релей и протокол рандеву), `internal/screen` (захват экрана GDI),
`internal/wininput` (ввод и буфер обмена), `internal/localws` (WebSocket окна),
`internal/wire` (формат сообщений).

## Безопасность

- **Рукопожатие — PAKE (SPAKE2, RFC 9382) на P-256.** Код подключения короткий
  (6 цифр), поэтому он не может быть «паролем в KDF»: в такой схеме одна
  попытка подключения позволяла бы подобрать код офлайн за секунды. В SPAKE2
  ни одно сообщение не даёт проверять варианты офлайн — только онлайн, по одной
  попытке на подключение. Точки M/N сверяются тестом с опубликованными в RFC;
  отдельный тест повторяет атаку офлайн-перебора и проверяет, что она не работает.
- **Онлайн-перебор:** после каждого неверного кода пауза растёт (2 с, 4 с, 8 с …
  до 5 минут) и не сбрасывается сменой кода; код меняется каждые 3 неверные
  попытки и после каждого сеанса. В окне показывается, сколько раз подряд
  вводили неверный код. Кнопка «новый код» сбрасывает паузу (её может нажать
  только человек за ПК).
- **Релей** ограничивает частоту запросов с одного IP (≈20 подключений в минуту)
  — против перебора ID и «заваливания» запросами.
- **С кодом** доступ даётся сразу — код и есть пароль. **Без кода** — только
  после «Да» на той стороне (по умолчанию выделено «Нет») с проверочным номером
  (SAS): при вмешательстве в канал номера у сторон разные.
- Данные: **AES-256-GCM**, у каждого направления свой ключ и счётчик nonce.
- **Окно** (локальный сервер на 127.0.0.1) отвечает только с токеном, только на
  Host 127.0.0.1/localhost (защита от DNS rebinding) и только своему Origin —
  чужие сайты и другие пользователи этого ПК не могут прочитать ID и код.
- Копия с правами администратора ничего не пишет в папку пользователя.
- Закрыл окно — приложение завершилось, компьютер не в сети.
- Принятые файлы не перезаписывают существующие, пути и имена очищаются,
  недокачанное удаляется. Перехват клавиатуры — только во время сеанса и только
  когда окно сеанса активно.

Остаётся учитывать:

- Текст, скопированный на той стороне во время сеанса, попадает в буфер
  подключившегося (как в AnyDesk). Не копируйте там пароли во время сеанса.
- `NordDesk.exe` не подписан — проверяйте, что скачиваете его с GitHub-релиза.
- Без кода (только ID) защиту от подмены даёт сверка проверочного номера.
- Если на компьютере уже есть вредоносная программа, никакая программа
  удалённого доступа его не защитит.

## Сервер (релей)

Релей работает на `143.246.193.103:8766` (адрес зашит в `NordDesk.exe` при
сборке, см. `NDSK_RELAY` в `.github/workflows/norddesk.yml`). Служба systemd:

```bash
cat > /etc/systemd/system/norddesk-relay.service <<'EOF'
[Unit]
Description=NordDesk relay
After=network.target

[Service]
ExecStart=/usr/local/bin/norddesk-relay -addr :8766
Restart=always
RestartSec=2
NoNewPrivileges=true

[Install]
WantedBy=multi-user.target
EOF
systemctl daemon-reload && systemctl enable --now norddesk-relay
ufw allow 8766/tcp comment 'NordDesk relay'
```

Если релей переехал — поменять `NDSK_RELAY` и пересобрать.

## Сборка вручную

```bash
cd norddesk
GOOS=linux   GOARCH=amd64 CGO_ENABLED=0 go build -o norddesk-relay ./cmd/relay
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -ldflags "-H=windowsgui -X main.defaultRelay=IP:PORT" -o NordDesk.exe ./cmd/norddesk
```

Лог приложения: `%AppData%\NordDesk\norddesk.log`.

## Дорожная карта — что ещё пригодится IT-специалисту

- **Системный агент (служба):** Ctrl+Alt+Del, управление экраном входа и окнами
  UAC прямо из сеанса, автозапуск.
- **Неприсмотренный доступ:** постоянный пароль в настройках окна, адресная
  книга своих машин с онлайн-статусом.
- **Файлы оттуда сюда** (сейчас — только туда), файловый менеджер, докачка.
- **P2P (ICE/hole-punching)** с релеем как запасным путём — меньше задержка и
  нагрузка на VPS.
- **Производительность:** DXGI Desktop Duplication и H.264 вместо GDI+JPEG.
- **Несколько мониторов**, курсор того компьютера в окне.
- **Во время сеанса:** затемнение экрана хоста, блокировка его ввода, режим
  «только просмотр», чат.
- **Учётки и аудит:** журнал подключений, 2FA, роли (как в NordKey).
- **Запись сеанса**, перезагрузка с автоподключением, Wake-on-LAN.
- **Распространение:** установщик, подпись кода (без предупреждения SmartScreen),
  автообновление, иконка приложения.

## Ограничения (честно)

- Только Windows x64; захват и ввод проверяются на реальной машине (в CI нет
  рабочего стола). На других ОС приложение умеет только подключаться к другим.
- Один монитор; Ctrl+Alt+Del и Win+L требуют системного агента.
- Окна «от администратора» управляются после «Права администратора для NordDesk»
  (ограничение Windows UIPI).
- Весь трафик идёт через релей.
